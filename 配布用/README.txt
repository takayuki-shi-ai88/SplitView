# Split View（画面半分＋Gemini）

Python を入れなくても使えます。このフォルダの **SplitView.exe** をダブルクリックしてください。

## 使い方

1. `SplitView.exe` をダブルクリックする
2. 右下付近に角丸の **Split View** ボタンが出る
3. 見たいアプリを前面にして、ボタンをクリックする
   → 左半分にその窓、右半分に Gemini

- ドラッグ … ボタンの移動（分割はしない）
- Esc … ボタンを閉じる
- 初回起動でデスクトップとスタートアップにもショートカットを作ります（Windows ログイン時にもボタンが出ます）

exe と同じ場所に `overlay-state.json` が1つできます。消しても次の起動で作り直されます。

Windows のスマートスクリーンが出たら「詳細情報」→「実行」で大丈夫です（自作の未署名 exe のため）。
